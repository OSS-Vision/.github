# 世界を変えるプロダクトを

PdM TOP Runner OSS-Vision

---

OSS-Vision株式会社は、島根県松江市を拠点に、OSSの開発文化に根ざしたプロダクトマネジメントを通じて、社会に変化を生むプロダクトづくりを支援する会社です。

何をつくり、誰にどんな価値を届けるのか。ユーザーと対話し、小さく試し、使いながら改善を重ねる。私たちは、OSSコミュニティが育んできたこの考え方を、企業や自治体のDX・AI活用、人材育成に活かしています。

## What We Do

- **OSS流プロダクトマネジメント教育**  
  ユーザーとの対話、継続的な改善、コミュニティづくり、プロダクト思考を学び、プロダクトを育てる人材を育成します。

- **DX・AI導入支援**  
  業務整理、データ分析、PoC、AI活用、業務システム構築まで、現場と一緒に段階的に進めます。

- **AI・エージェントを活用した業務基盤の研究・開発**  
  AIを、人と業務システムをつなぐインターフェースとして捉え、企業ごとの業務を支援するエージェント基盤を開発しています。

- **Rubyを中心としたOSSコミュニティとの連携**  
  RubyやOSSのコミュニティと縁の深い松江から、OSSの思想・文化を活かした技術活用、人材育成、地域DXに取り組みます。

## Our Vision

企業ごとに歴史があり、仕事の進め方があり、働く人がいます。現場と対話し、その会社に合った変化の方法を一緒につくる。そして、その企業自身が変化を続けられる状態をつくる。それこそがDXだと考えています。

一社ずつ丁寧にDXを進め、知見を共有し、企業同士が学び合う。その積み重ねが地域全体へ広がり、誰かが一気に作り替えることのできない、強く持続可能なDXの「面」になっていく。

世界中の人々が参加しながら、大きなソフトウェアを育ててきたOSSのように。

**OSSの思想を、ソフトウェアだけでなくプロダクト・DXへ。**

OSS-Visionは、松江からそんな未来をつくっていきます。
